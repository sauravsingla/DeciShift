# Code of Conduct

DeciShift welcomes technical contributions, questions, reproducibility reports, and respectful disagreement.

## Expected conduct

- Be respectful and specific when discussing code, results, assumptions, and limitations.
- Critique ideas and implementations rather than people.
- Make room for contributors with different backgrounds and levels of experience.
- Protect private information and do not publish credentials, personal data, or sensitive reports.
- Keep discussions relevant to the project and avoid spam, harassment, discrimination, threats, or intimidation.

## Maintainer responsibilities

Maintainers may edit or remove content, close discussions, restrict participation, or block accounts when behavior is disruptive, abusive, unsafe, or unrelated to the project. Moderation decisions should be based on observable conduct, not technical disagreement.

## Reporting

Do not publish sensitive security information in a public issue; follow [SECURITY.md](SECURITY.md). For conduct concerns containing private information, use an available private GitHub contact/reporting channel or contact the repository owner through their GitHub profile rather than posting sensitive details publicly.

This code of conduct applies to project repositories, issues, pull requests, discussions, and other project-managed collaboration spaces.
