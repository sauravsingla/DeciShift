# Support

DeciShift is an open-source project. Support is community/maintainer best-effort and has no guaranteed response time or service-level agreement.

## Where to ask

- **Usage, design, or interpretation questions:** use [GitHub Discussions](https://github.com/sauravsingla/DeciShift/discussions).
- **Reproducible bugs:** open a GitHub issue using the bug-report template.
- **Feature ideas:** use the feature-request template and describe the decision-system problem first.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) and do not publish sensitive details in a public issue.

## Useful information for a bug report

Include the DeciShift version, Python version, operating system, installation method, minimal reproducible input/configuration, complete error text, and whether the problem occurs on the bundled examples.

When evidence verification, attribution, or Decision Contracts are involved, include the smallest non-sensitive evidence/configuration needed to reproduce the behavior. Never upload confidential data merely to obtain support.

## Scope

The project focuses on local, CPU-first behavioral regression testing of versioned decision systems. Questions about hosted model serving, general workflow orchestration, feature stores, production monitoring platforms, or cloud infrastructure may be outside project scope unless they concern a concrete DeciShift integration.
