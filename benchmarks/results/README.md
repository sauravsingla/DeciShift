# Benchmark result snapshots

Files in this directory are machine-generated by `benchmarks/evaluate_flow_attribution.py`.

Each snapshot must contain the exact source commit SHA used for the run. Do not hand-edit timing, memory, cache, or convergence values. The default published run covers 10K and 100K records; 1M is an optional explicitly requested run because it is materially more expensive.

The source of truth for the protocol is `docs/evaluation-study.md`.
